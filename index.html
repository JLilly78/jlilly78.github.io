C++ Music Player 🡕

(A work in progress). Utilizes the PortAudio library with ASIO drivers. I wrote the logic for the callback function to feed in wav file data to the output buffer. It makes use of a PortAudio library ring buffer to cache the audio data within a thread function and then sends that to the callback function to be sent to the ASIO output buffer. It makes use of global states to know when to pause/stop/resume/play. The program is a WIN32 project, so it uses the older style of Window. It's capable of WAV and MP3 playback. It displays the track name and number for now.

Callback function
This callback function supplies the output buffer with the bytes from a ring buffer which holds WAV PCM data for playing. Line 15 is the line that writes to the output buffer, specifically. You'll also notice the if condition on line 3, this exists to check the global "pause" variable to see if it's true and, if so, sends 0's to the output buffer on line 6 to effectively pause playback.
Wave file parsing function
This function takes a file path as a parameter, finds and opens the file, reads the header info and stores the header into a struct called "waveHeader". It packs this struct as well as the pointer to the FILE object in a larger struct and returns that larger struct. This is used as an argument in the call to the main music player function.
Main music player function
This function is what initializes and controls playback of the input wave file. It makes use of some of the PortAudio library examples for how to write the function that initializes the library and opens the playback stream. On line 55, you'll see the Pa_OpenStream function which is what initializes the playback stream with the correct parameters pulled from the wave file headers given by the user-provided wave file. A while loop on line 71 exists to constantly check if the playback should end if the stop global is true. This would happen if the user pressed the stop button on the UI.
